# Bhupendra VyronOS visual identity

- OS: Bhupendra VyronOS
- Login greeting: Welcome to Bhupendra's Workstation
- Brand signature: Bhupendra
- Palette: charcoal / black with restrained gold highlights
- Mood: royal Rajasthan architecture, forts, stone arches, elegant and restrained
- Emblem: custom SVG lion-inspired geometric mark (concept artwork; not a heraldic reproduction)

Assets in this directory are initial vector branding. Login-screen configuration and wallpaper assets will be wired into the build in subsequent steps.
