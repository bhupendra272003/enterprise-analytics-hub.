# VyronOS Analytics Workstation — Quick Start

## Applications
- **Firefox:** research, documentation, dataset downloads.
- **LibreOffice Calc:** spreadsheet formulas, tabular review, and export.
- **Python:** repeatable data preparation and analysis.
- **MySQL:** query, validate, and aggregate structured data.
- **Terminal:** run commands and manage project folders.

## Recommended analytics workflow
1. Preserve raw files; work from copies.
2. Record cleaning rules and assumptions.
3. Validate row counts, duplicates, missing values, and key relationships.
4. Explore and aggregate with SQL.
5. Use Python for repeatable transformations and analysis.
6. Cross-check totals and document findings before sharing.

## Security and account setup
- Use the administrator-provided account/role setup workflow.
- Never commit passwords, tokens, or other secrets to repositories.
- Keep security updates enabled.
- Verify downloaded datasets before opening them.

## Current status
This guide describes the intended workflow, not proof of a completed bootable OS. The VyronOS project remains under build and runtime validation.
